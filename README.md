# PTCGO

This First Third 2025 study project focuses on developing a tool for managing Pokémon Trading Card Game Online (PTCGO) cards, building decks, and tracking deck progress. It also serves as a platform for enhancing JavaScript development skills, utilizing technologies such as NestJS, React, and related libraries.

The primary goal of this project is to study microfrontends with React. Throughout the development process, I am documenting my concerns, learnings, and key decisions within the application itself. These notes are intended to provide context, explain challenges encountered, and highlight the solutions and insights gained.

## PROJECT STATUS

This application is not fully complete. However, the primary goal of studying microfrontends with React and RSBuils was achieved. I may return to this project in the future to complete the remaining features. In the meantime, I invite anyone interested to contribute and finish what is not done.

## FINAL CONSIDERATIONS

This application is a practice project built to explore technologies and concepts. It's not intended for commercial use and may not adhere to best practices for production environments. Feel free to explore, contribute, or provide feedback. Thank you for checking it out!
